# Privacy Policy

Effective date: 2026-11-21

This policy covers the Blacksun reference board tool ("the tool"), an internal tool used by the Blacksun development team. The tool connects to the Pinterest API.

## Who uses the tool

Only members of the Blacksun development team use the tool. It is not offered to the public and has no user sign-up.

## What data the tool accesses

The tool accesses the Pinterest account that the team itself authorizes. From that account it reads:

- board names and descriptions
- pins saved on those boards (image links, titles, descriptions, source links)
- basic account information needed to identify the authorized account (for example the account name)

The tool does not access the accounts of other Pinterest users. It does not collect personal information about other people.

## How the data is used

The data is used for one purpose: organizing visual reference material for game development inside the team.

The tool does not use the data for advertising, profiling or analytics about individuals.

## Storage and retention

- Access tokens are stored only on the team's own computers and are not shared.
- Reference data fetched from Pinterest is stored only on the team's own computers.
- The team deletes the stored data and tokens when the tool is no longer used, or when access is revoked.

## Sharing

The team does not sell, rent or share data obtained through the Pinterest API with third parties. The tool does not republish or redistribute Pinterest content.

## Revoking access

The account owner can revoke the tool's access at any time in Pinterest account settings (Security, then connected apps). After access is revoked, the tool can no longer read the account, and the team deletes the stored tokens.

## Changes

If this policy changes, the new version is published in this repository with a new effective date.

## Contact

Questions and deletion requests: open an issue at https://github.com/HHSic/blacksun-info/issues
