# Blacksun (블랙썬)

Blacksun is a 3D dungeon-crawling RPG in development by a small indie team. The player leads a party of mercenaries up a tower, floor by floor.

This repository is the public information page for the project. The game source code is kept in a separate private repository.

## Reference board tool

The team uses a small internal tool that connects to the Pinterest API. The tool reads the boards and pins of the team's own Pinterest account, so that visual reference material (UI and art mood boards) can be organized during development.

- It accesses only the team's own Pinterest account.
- It does not collect data from other Pinterest users.
- It does not publish, sell or redistribute Pinterest content.

See [PRIVACY.md](PRIVACY.md) for the privacy policy.
